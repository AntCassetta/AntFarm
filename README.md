# AntFarm 🐜

My personal engineering sandbox — a collection of proof-of-concept 
projects, experiments, and explorations that don't yet have a home 
of their own.

## What's in here

| Project | Description | Tech |
|---|---|---|
| DrinkTarot - Card Game POC | Proof-of-concept for a card game engine | Python |
| Healthcare DB Mockup | Schema design for a healthcare database system, built to my own spec | Python / SQL |
| Interview Prep | Python exercises and algorithm practice | Python |
| Image Resizer | Utility script for automatic image resizing | Python |
| Take-Home Projects | Code from technical interview assignments | Python |

## Why this repo exists
Not every idea deserves its own repository from day one. AntFarm is 
where things live while they're being figured out — some of these 
may grow into standalone projects, others are just interesting 
problems worth solving.

## Main stack
Python — because it's the right tool for thinking fast.
